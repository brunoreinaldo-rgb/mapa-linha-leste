Como usar o Sistema

1. Tema e Mapa: Alterne entre Modo Claro/Escuro no botão (☀️/🌙) ou troque o tipo de mapa (Claro, Escuro, Satélite, Ruas) diretamente na barra superior do mapa.

2. Categorias Automáticas: Use o botão "Pastas". O sistema criará categorias usando o nome das suas pastas.

3. Exportar Dados: Vá em Configurações > Exportar Dados. Ao enviar esse arquivo .json para sua equipe, basta arrastá-lo para a tela que tudo será pré-configurado.
